# Task Manager (React + TypeScript)

Управляйте задачами в удобном интерфейсе с возможностью создания, редактирования и фильтрации.

## Описание функционала

Приложение "Менеджер задач" предоставляет следующий функционал:
- 📝 Создание задач с указанием:
  - Названия (обязательно)
  - Описания
  - Категории (Bug/Feature/Documentation)
  - Статуса (To Do/In Progress/Done)
  - Приоритета (Low/Medium/High)
- ✏️ Редактирование существующих задач
- 🗑️ Удаление задач
- 🔍 Просмотр списка задач с фильтрацией по статусу
- 💾 хранениее задач на сервере

## Суть архитектуры FSD (Feature-Sliced Design):

1. **Слоистая структура:**

app/ - Инициализация приложения (роутинг, провайдеры)

pages/ - Страницы как точки входа

features/ - Бизнес-функции (например, "создание задачи")

entities/ - Бизнес-сущности (например, "задача", "пользователь")

shared/ - Переиспользуемый код (UI, утилиты)

2. **Ключевые принципы:**

Вертикальные слайсы вместо горизонтальных (не "components/utils", а "feature/component")

Один модуль = одна ответственность

Чёткие правила зависимостей между слоями:

text
app ← pages ← features ← entities ← shared
Преимущества:

Масштабируемость (каждый фич-слайс автономен)

Чёткое разделение зон ответственности

Упрощённый поиск кода (по функциональности)

Готовность к микросервисному разбиению

3. **Отличия от других подходов:**

В отличие от MVC, делит код по бизнес-возможностям, а не по техническим ролям

По сравнению с Atomic Design, ориентирован на бизнес-логику, а не на компоненты
